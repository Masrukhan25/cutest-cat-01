A ginger kitten, drawn by a program. Big bright eyes, a head tilt, blush cheeks,
whiskers, a curled tail with a cream tip, and a pink ball of yarn at its paw.
The program draws the cat with Pillow and writes one 1024x1024 PNG to
/output/entry.png. Deterministic: two runs write the same bytes.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.png` goes (default `/output`).
